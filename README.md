# CIPP/US Study Games

Interactive drills for the IAPP Certified Information Privacy Professional/US exam.
Six matching decks, a sorting game, and a 40-question quiz bank, in a single HTML
file with no dependencies.

**Play it:** https://davidalex89.github.io/cipp-us-study-games/

## Modes

| Mode | What it drills |
|---|---|
| Article → Purpose | The seven Articles of the Constitution and what each establishes |
| Court Cases | 16 cases matched to their holdings, Olmstead through Carpenter |
| Law Names | 12 acronyms expanded |
| Law → Requirement | The specific obligation each statute imposes |
| State Law Features | What distinguishes each state comprehensive law |
| Private Right of Action Sort | Which of 16 statutes let individuals sue |
| Regulator → Authority | Who enforces what |
| Quiz | 20 random questions per set, drawn from 40, each with an explanation |

The quiz reshuffles on every set, so repeat runs are not the same twenty questions.

## Running it locally

Download `index.html` and open it in a browser. No build step, no server, no
network calls. It works offline and on a phone.

## Scope and caveats

This is personal study material, not a course. It is not affiliated with or
endorsed by the IAPP, and it is not a substitute for the official body of
knowledge — the exam covers considerably more ground than what is here.

US privacy law moves. Cure periods sunset, agencies reorganise, and cases get
overruled. Check anything you plan to rely on against a current source, and treat
a wrong answer here as a prompt to go read the statute rather than as settled
fact.

## Use

Free to use, copy, adapt, and share. No conditions and nothing to attribute.

Corrections are welcome — open an issue or a pull request. Getting a holding or a
date wrong in a study aid is worse than leaving it out, so specific corrections
with a source are especially useful.
